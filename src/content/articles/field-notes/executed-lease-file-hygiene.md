# Signed but unscanned is not in the file

The lease feels done when the last signature lands. Then the PDF never reaches the lease folder. Months later the commencement on the rent roll does not match anyone's memory, and the only copy anyone can find is a tenant scan missing the exhibits. The signature happened. The file did not. Those are different events, and the rent roll should be allowed to say so.

## What counts as executed on file

"Executed" means the parties signed. "On file" means a complete copy sits where the rest of the operation looks, and a person has checked it. Both have to be true before the lease log says complete.

A lease is executed on file only when all of these are true.

- Every page is in one PDF, including exhibits, rules, guaranty, and any commencement letter the form calls for.
- Each signature block the form asks for is signed, and each date line the form asks for is filled. A signature without the exhibit it incorporates is a partial.
- The named landlord and tenant match the entities you invoice and the entities on the insurance tracker. A trade name on the storefront is not a substitute.
- The PDF has no comment balloons, no "DRAFT" watermark, and no redline still showing. A negotiation copy is not the executed copy, even when the business terms look final.
- Amendments, renewals, and side letters live in the same folder. The folder opens with a one-line index: base lease date, each later document's date, commencement, expiration. If you cannot explain the stack in that one line, the stack is not finished.

A "completed" message from a signing portal is a pointer. The executed file is the combined PDF you downloaded and saved. Wet ink in a cabinet counts only after it is scanned into that folder and the scan's page count matches the paper. Until then the status is executed, not in file. Do not mark the checklist green to retire the discomfort.

Commencement, expiration, and option windows get copied from that PDF onto the rent roll and the critical-dates calendar. If the PDF is not there, those dates stay blank or stay marked unresolved. Inventing them from a broker's email is how the roll drifts from the document.

## One drop slot, emptied on a cadence

Pick one inbox. Name it. Everything that arrives — a portal download, an email PDF, a phone photo of a signature page — goes there the day it arrives, and nowhere else. People will still send leases to a personal address. The rule is that the receiver forwards into the slot the same day, then works from the slot, not from the original thread.

Once a week, one person empties the slot. Each item does one of two things. It moves into a lease folder and the index line updates, or it goes back to the sender with a note that names the missing page. The slot is not a second archive. If it still has files when the week closes, the week is not finished. A slot that quietly becomes a folder of "I'll file this later" is the signed-but-unscanned problem with a tidier name.

The same pass catches the cousin problems: a commencement agreement signed and never scanned, a guaranty the tenant emailed to the broker, a side letter on rent that never made the index. The weekly empty is short because the slot was not allowed to become the file.

**Illustrative closing.** A hypothetical inline deal signs on a Thursday in the office. The tenant leaves with a paper set. The owner's set stays on the credenza, then slides under a stack of vendor invoices. The lease log says executed because both parties signed. The lease folder is empty. Monday's job is the scan, the page count against the paper, the index line, and the dates copied onto the roll. The congratulations note can wait until those four things exist.

A model can draft the index line from a PDF and flag a missing exhibit by page count. A person confirms the page count against the paper and is the one who changes the status from "not in file" to "in file."

## The next step

1. Open every lease folder and write one index line, or write "no complete PDF."
2. Create the drop slot and forward into it anything signed in the last ninety days that is not already in a folder.
3. Empty the slot this week. Incomplete items go back the same day, with the missing page named.
4. On the rent roll, mark any tenancy whose folder failed the test as "executed, not in file," and leave the dates unresolved until the PDF is there.
